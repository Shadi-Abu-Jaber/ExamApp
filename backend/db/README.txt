==============================================================================
ExamApp — DB layer (HYBRID: relational + JSONB)
==============================================================================

קבצים בתיקייה הזו:
  01_schema.sql       — יצירת טבלאות users / exams / submissions.
                        עמודת questions ב-exams היא JSONB (HYBRID).
  02_seed.sql         — הזרעת נתוני דמו (2 משתמשים, 2 בחינות).
  03_queries.sql      — שאילתות הדגמה: חיבוריות + שליפת users/exams +
                        לולאה על השאלות מתוך JSONB עם jsonb_array_elements.
  connect-test.js     — סקריפט Node שמדגים את אותו זרימה מתוך הקוד:
                        חיבור, שליפה, לולאה על השאלות כאובייקטי JSON.
  README.txt          — הקובץ הזה.

==============================================================================
דרישות מקדימות
==============================================================================
* PostgreSQL 15+ מותקן ופועל על 127.0.0.1:5432.
* קובץ backend/.env עם משתני PG_HOST / PG_PORT / PG_USER / PG_PASSWORD /
  PG_DATABASE (העתיקו מ-backend/.env.example).
* מתוך backend/ הריצו `npm install` פעם אחת כדי להוריד את חבילת pg.

==============================================================================
הרצה — סדר פעולות מומלץ (מהשורש של הריפו)
==============================================================================

  # 1. יצירת מסד הנתונים (פעם אחת בלבד)
  PGPASSWORD='<your-pwd>' psql -U postgres -h 127.0.0.1 \
      -c "CREATE DATABASE examapp;"

  # 2. יצירת סכמה
  PGPASSWORD='<your-pwd>' psql -U postgres -h 127.0.0.1 -d examapp \
      -f backend/db/01_schema.sql

  # 3. זרע נתונים
  PGPASSWORD='<your-pwd>' psql -U postgres -h 127.0.0.1 -d examapp \
      -f backend/db/02_seed.sql

  # 4. הרצת שאילתות הדגמה (SQL בלבד)
  PGPASSWORD='<your-pwd>' psql -U postgres -h 127.0.0.1 -d examapp \
      -f backend/db/03_queries.sql

  # 5. בדיקת חיבוריות + לולאה על JSONB מתוך Node
  node backend/db/connect-test.js

==============================================================================
מה הסקריפטים מדגימים (בדיוק מה שדורש סעיף המשימה)
==============================================================================
* בדיקת חיבוריות           → סעיפים 1 בכל אחד מהסקריפטים.
* שליפת כל המשתמשים        → סעיף 2.
* שליפת כל הבחינות         → סעיף 3.
* לולאה על השאלות כ-JSON   → סעיף 4 (Node, jsonb בקוד) + סעיף 4 (SQL, jsonb_array_elements).
* שאילתת JSONB מתקדמת      → סעיף 5 ב-03_queries.sql (חיפוש לפי תוכן השאלה).
==============================================================================
