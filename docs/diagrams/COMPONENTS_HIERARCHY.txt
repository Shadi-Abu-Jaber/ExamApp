Shared UI Components
====================

PageHeader
- מציג כותרת, תיאור ופעולות עבור כל דף.

Card
- משמש להצגת מידע בתוך כרטיס מעוצב.

Button
- כפתור פעולה משותף למערכת.

Input
- שדה קלט טקסט.

Textarea
- שדה להזנת תשובות פתוחות.

Alert
- הודעת הצלחה או שגיאה.

Badge
- הצגת סטטוס קצר, לדוגמה PUBLISHED או GRADED.

EmptyState
- הודעה כאשר אין נתונים להצגה.

LoadingSpinner
- חיווי טעינה בזמן קבלת נתונים.
