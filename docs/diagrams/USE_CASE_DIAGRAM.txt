ExamFlow - Use Case Diagram
===========================

להציג את הפעולות המרכזיות שכל משתמש יכול לבצע במערכת.

Use Case Relations
==================

(Create Exam)
      |
      | includes
      v
(Edit Exam) -------- includes --------> (Add Questions)

(Publish Exam)
      |
      | requires
      v
(Exam in DRAFT Status)


(Start Exam)
      |
      | includes
      v
(Create Submission)


(Answer Questions)
      |
      | includes
      v
(Save Answers)


(Submit Exam)
      |
      | may include
      v
(Auto Grade Closed Questions)


(Grade Submission)
      |
      | includes
      v
(Add Feedback)


(Publish Results)
      |
      | enables
      v
(View Published Results)
