ExamFlow - Main Entities Used by Database, Mocking and Views
============================================================

מטרת המסמך:
להציג את הישויות המרכזיות שבהן משתמשת המערכת,
הן בצד השרת והן במצב Mock בצד הלקוח.


1. User
=======

תיאור:
משתמש רשום במערכת.

Attributes:
- id: מזהה ייחודי של המשתמש.
- fullName: שם מלא.
- email: כתובת דואר אלקטרוני.
- password / passwordHash: פרטי אימות מאובטחים.
- role: תפקיד המשתמש.

Role Values:
- ADMIN
- LECTURER
- STUDENT

Relations:
- Lecturer יכול ליצור מבחנים רבים.
- Student יכול לקבל מבחנים ולהגיש תשובות.


2. Exam
=======

תיאור:
מבחן שנוצר ומנוהל על ידי מרצה.

Attributes:
- id: מזהה מבחן.
- title: שם המבחן.
- description: תיאור המבחן.
- lecturerId: מזהה המרצה היוצר.
- durationMinutes: משך זמן המבחן.
- startTime: זמן התחלה.
- endTime: זמן סיום.
- status: סטטוס המבחן.
- resultsPublished: האם התוצאות פורסמו.

Status Values:
- DRAFT
- PUBLISHED
- CLOSED

Relations:
- Exam שייך למרצה אחד.
- Exam מכיל שאלות רבות.
- Exam משויך לסטודנטים.
- Exam כולל הגשות רבות.


3. Question
===========

תיאור:
שאלה השייכת למבחן.

Attributes:
- id: מזהה שאלה.
- examId: מזהה המבחן.
- questionText: טקסט השאלה.
- questionType: סוג השאלה.
- points: מספר נקודות.
- orderIndex: מיקום השאלה במבחן.

Question Type Values:
- MCQ
- TRUE_FALSE
- SHORT_TEXT
- ESSAY

Relations:
- Question שייכת למבחן אחד.
- Question יכולה לכלול אפשרויות תשובה.
- Question יכולה לקבל תשובות רבות מסטודנטים.


4. QuestionOption
=================

תיאור:
אפשרות תשובה עבור שאלה סגורה.

Attributes:
- id: מזהה אפשרות.
- questionId: מזהה השאלה.
- optionText: תוכן האפשרות.
- isCorrect: האם האפשרות נכונה.

Relations:
- QuestionOption שייכת לשאלה אחת.


5. ExamStudent
==============

תיאור:
ישות קישור בין מבחן לסטודנט.

Attributes:
- examId: מזהה מבחן.
- studentId: מזהה סטודנט.

Purpose:
- קובעת לאילו סטודנטים הוקצה כל מבחן.

Relations:
- Exam אחד יכול להיות משויך לסטודנטים רבים.
- Student אחד יכול לקבל מבחנים רבים.


6. Submission
=============

תיאור:
הגשת מבחן או ניסיון ביצוע של סטודנט.

Attributes:
- id: מזהה הגשה.
- examId: מזהה מבחן.
- studentId: מזהה סטודנט.
- status: מצב ההגשה.
- startedAt: זמן התחלה.
- submittedAt: זמן הגשה.
- totalScore: ציון סופי או חלקי.
- feedback: משוב כללי.

Submission Status Values:
- IN_PROGRESS
- SUBMITTED
- GRADED

Relations:
- Submission שייכת לסטודנט אחד.
- Submission שייכת למבחן אחד.
- Submission כוללת תשובות רבות.


7. Answer
=========

תיאור:
תשובה של סטודנט לשאלה מסוימת.

Attributes:
- id: מזהה תשובה.
- submissionId: מזהה הגשה.
- questionId: מזהה שאלה.
- answerText: תשובה טקסטואלית.
- selectedOptionId: אפשרות שנבחרה בשאלה סגורה.
- score: ניקוד עבור התשובה.
- feedback: משוב לתשובה.

Relations:
- Answer שייכת להגשה אחת.
- Answer מתייחסת לשאלה אחת.
- Answer יכולה להתייחס לאפשרות תשובה שנבחרה.

Entities in MockDbService
=========================

MockDbService מדמה את הישויות הבאות בתוך localStorage:

- Exam
- Question
- QuestionOption
- Submission
- Answer

במצב Mock קיימים:
- מבחן זמין לדוגמה עבור סטודנט.
- מבחן קודם עם תוצאה שפורסמה.
- Submission מדומה עבור הצגת תוצאות.
- תשובות מדומות לצורך הדגמה ובדיקה.

שירותי StudentService ו-SubmissionService משתמשים בישויות אלה
כאשר VITE_USE_MOCK_API=true.
